## WHICH FILE TO USE

Two source files were provided:
- **Square full bleed** (`Icon set - SQUARE full bleed ... 1024px.png`): blue edge to edge, no rounded corners. **Use this one by default.** Google Play applies its own rounded mask, and Android and iOS do the same for the app icon, so the square file is the correct source.
- **Rounded** (`Icon set - ROUNDED ... 1024px.png`): only use this if the owner explicitly asks for the rounded version. It is a preview, not a store upload.

Do NOT use any file that contains the red "FREE" ribbon. If the chosen file contains red pixels or the word "FREE", **stop immediately** and report it.

Both files are 1024×1024. Check this. If the size differs, stop and report it. Do not resize.

## SCOPE

Only the app icon files and the icon settings in `app.json` change. Do NOT change the splash screen, the app name, scanner, PDF generation, permissions, ads, navigation, folders, or screen code. Do NOT upgrade any package. Do NOT build or submit.

## NO CROPPING, NO SHRINKING

- Use the chosen logo at its exact 1024×1024 size. Do not crop, zoom, pad, or scale it.
- Only Expo's own icon generation during prebuild may resize it. Don't pre-resize files in the project.
- The corner brackets and the "PDF Scanner" text are inside the Android adaptive icon's safe zone, so keep them unchanged.

## STEPS

1. **Save the chosen logo as `assets/images/icon.png`**, unchanged, 1024×1024, fully opaque (no transparency). This is the main app icon for Android and iOS.

2. **Create the Android adaptive foreground** `assets/images/icon-foreground.png`, 1024×1024, same size, from the same source:
   - Make every blue background pixel transparent, and keep all white pixels (the brackets, "PDF", and "Scanner") exactly as they are.
   - Use this script (install Pillow with `pip install pillow` if needed, and tell me):
     ```python
     from PIL import Image
     img = Image.open("assets/images/icon.png").convert("RGBA")
     px = img.load()
     w, h = img.size
     for y in range(h):
         for x in range(w):
             r, g, b, a = px[x, y]
             if abs(r - 37) < 14 and abs(g - 99) < 14 and abs(b - 235) < 14:
                 px[x, y] = (0, 0, 0, 0)
     img.save("assets/images/icon-foreground.png")
     assert img.size == (1024, 1024)
     ```
   - Check the output: still 1024×1024, the blue is gone, and the white artwork is fully present.

3. **Update `app.json`:**
   - `expo.icon` → `"./assets/images/icon.png"`
   - `expo.android.adaptiveIcon.foregroundImage` → `"./assets/images/icon-foreground.png"`
   - `expo.android.adaptiveIcon.backgroundColor` → `"#2563EB"`
   - Leave every other plugin and setting unchanged.

4. **Remove old icon references** that point to previous logo files. If an old file is still used somewhere, keep it and tell me where.

5. The splash screen stays as it is.
