# Prompt for OpenCode — Show the Logo Full Size on the Android Launcher (v3)

Paste everything below the `---` into OpenCode. Read AGENTS.md first and follow it.

## WHAT'S WRONG

On the phone's launcher, the logo appears smaller than the square artwork. The cause is the Android adaptive icon setup:

- An adaptive icon has a foreground layer and a background layer. Android only guarantees that the central part of the foreground is visible, so the launcher scales the whole foreground down to fit that safe zone.
- Our foreground is the full logo (brackets, "PDF", and "Scanner"), so the launcher shrinks all of it to fit, making the logo look smaller than the square we designed.

The fix is to stop using the adaptive foreground and let the launcher use the full square logo as the icon. The launcher will then show the square exactly as designed. It may apply a rounded or circular mask at the corners, but it won't shrink the artwork.

## SOURCE

- Use the **square full-bleed logo** (1024×1024, blue edge to edge, no rounded corners, no red FREE ribbon) as `assets/images/icon.png`. If the file contains red pixels or the word "FREE", stop and report it.
- Use it exactly as provided. Do NOT crop, zoom, pad, or resize it.

## SCOPE

Only the icon settings in `app.json` and the icon files change. Do NOT change the splash screen, the app name, the scanner, PDF generation, permissions, ads, navigation, folders, or screen code. Do NOT upgrade any package. Do NOT build or submit.

## STEPS

1. Place the square logo at `assets/images/icon.png`, untouched, 1024×1024, opaque.

2. **Remove the adaptive icon foreground** from `app.json`:
   - Delete `expo.android.adaptiveIcon.foregroundImage`.
   - Delete `expo.android.adaptiveIcon.backgroundColor` as well, unless it's needed to keep the build valid. If the build requires an `adaptiveIcon` object, keep only `backgroundColor` set to `"#2563EB"` and no foreground, and tell me.
   - Delete any `assets/images/icon-foreground.png` file that is no longer used, and tell me you did.
   - `expo.icon` stays `"./assets/images/icon.png"`.

3. Leave every other plugin and setting unchanged.
